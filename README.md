# Dijkstra-s-Algorithm-using-the-NY-State-map
Implementation of Dijkstra's Algorithm using NY State, Monroe County, and University of Rochester map to find the shortest path

# Configuration
3 files(.txt) are provided with GPS Coordinates

If running on Eclipse, (Run Configurations) and provide one of the 3 (Arguments) listed below:
1. To show both the map and the directions
		(java StreetMap mapname.txt --show --directions From To) eg (java StreetMap ur.txt --show --directions HOYT MOREY)
2. To just show the map
		(java StreetMap mapname.txt --show) eg (java StreetMap nys.txt --show)
3.  To just show the directions
		(java StreetMap mapname.txt --directions From To) eg (java StreetMap ur.txt --directions HOYT MOREY)
